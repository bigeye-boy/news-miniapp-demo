# Tab Bar Icons

This directory contains the normal and selected icons used by the app-level tab bar.

## Files

- `home.png`: News tab normal icon.
- `home-active.png`: News tab selected icon.
- `list.png`: Profile tab normal icon.
- `list-active.png`: Profile tab selected icon.

## Configuration

The icons are referenced from `app.json` under `tabBar.list`.

When adding or replacing icons, keep filenames stable or update `app.json` at the same time.
