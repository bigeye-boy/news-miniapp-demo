# Badge Component

The badge component is a compact label used inside the Profile page's npm component demo.

## Properties

| Property | Type | Default | Purpose |
| --- | --- | --- | --- |
| `text` | `String` | empty | Text displayed inside the badge. |
| `type` | `String` | `info` | Visual style. Supported values in this demo are `info` and `success`. |
| `theme` | `String` | `theme-light` | Applies light or dark styles. |

## Teaching Focus

Use this component to explain how a small npm component can expose a simple property API while keeping its own style variants internal.
