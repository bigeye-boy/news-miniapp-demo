# Card Component

The card component is a simple container for demonstrating npm component properties and slots.

## Properties

| Property | Type | Default | Purpose |
| --- | --- | --- | --- |
| `title` | `String` | empty | Main card title. |
| `subtitle` | `String` | empty | Optional secondary text. |
| `theme` | `String` | `theme-light` | Applies light or dark styles. |

## Slot

The default slot lets the parent page render custom content inside the card.

## Teaching Focus

Use this component to explain package component structure, property passing, slot content, and dark mode adaptation inside a component's own style scope.
