# Documentation Assets

This directory contains supporting documentation and diagrams for the training project.

## Current Content

- `MVVM-Architecture.drawio`: editable source diagram for explaining the app's MVVM-style structure.
- `MVVM-Architecture.jpg`: preview image of the architecture diagram.

## Guidelines

- Keep diagram source files here so they can be updated later.
- Keep generated presentation files outside this project unless they are intentionally part of the app source.
- Do not put runtime build output in this directory.
